## ⚠️ نکات مهم

- 🔒 **دسترسی ادمین الزامی است.** اگر برنامه را بدون دسترسی ادمین اجرا کنید، دستورات `netsh` اجرا نمی‌شوند و DNS تغییر نخواهد کرد.
- 🌐 **نام کارت شبکه باید «Wi-Fi» باشد.** برنامه به‌طور خودکار به دنبال کارت شبکه‌ای می‌گردد که در نامش عبارت `Wi-Fi` یا `Wireless` وجود داشته باشد. اگر کارت شبکهٔ شما نام دیگری دارد (مثلاً زبان سیستم فارسی است)، ممکن است برنامه آن را پیدا نکند.
- 🔌 **اتصال به شبکه حفظ می‌شود.** تغییر DNS اتصال فعلی شما را قطع نمی‌کند، اما برای اعمال کامل ممکن است نیاز به `ipconfig /flushdns` داشته باشید.
- 🛡️ **پشتیبان‌گیری:** قبل از تغییر، می‌توانید گزینهٔ **۲ (Show Current DNS)** را اجرا کنید تا مقادیر فعلی را ببینید.

## 🩹 رفع مشکلات رایج

### ❌ «Could not find Wi-Fi interface»

- مطمئن شوید که به Wi-Fi متصل هستید.
- در ترمینال دستور `netsh interface show interface` را اجرا کنید و ببینید کارت شبکه با چه نامی ثبت شده است. اگر نام آن `Wi-Fi` یا `Wireless` نیست، باید مقدار ثابت در تابع `get_wifi_name()` را مطابق نام واقعی تغییر دهید.

### ❌ DNS تغییر می‌کند اما سایت‌ها باز نمی‌شوند

- یک‌بار دستور زیر را در ترمینال اجرا کنید:
```bash
ipconfig /flushdns
```
- سپس مرورگر را ببندید و دوباره باز کنید.

### ❌ خطای `Requested operation requires elevation`

ترمینال را با دسترسی ادمین باز کنید (Run as administrator).

در تابع `dns_Menu()`، دیکشنری `dns_options` را به‌صورت زیر گسترش دهید:

dns_options = {

}

print(center_text("8) Quad9 : (9.9.9.9 , 149.112.112.112)"))
